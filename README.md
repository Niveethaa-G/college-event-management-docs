# College Event Management System

## Introduction

The College Event Management System is a web-based application
used to manage and organize college events efficiently.

## Features

- Event registration
- Student participant registration
- Event schedule management
- Venue management
- View event details
- Generate event reports

## Technologies Used

- HTML
- CSS
- JavaScript

## Installation

1. Download the project.
2. Open the project folder.
3. Open index.html in a browser.

## Usage

1. Login to the system.
2. Select an event.
3. Register for the event.
4. View the event schedule.
5. Check participant details.
6. Generate the event report.
